geometor.phyllotaxis.compute_node_path(origin: Vec3, parent_tangent: Vec3, radial_dir: Vec3, binormal_dir: Vec3, age: int, generation: int, config: MeristemConfig) → tuple[list[Vec3], Vec3, Vec3, Vec3]¶

Evaluate a node’s 3D trajectory $gamma(s)$ for $s in [0, text{age}]$ from origin.

At $s = 0$, $gamma(0) = text{origin}$. As $s to text{age}$, the path advances outward along radial_dir and lifts/curves along parent_tangent with optional helical twist around binormal_dir.

Parameters:

  • origin – 3D point on the parent meristem where this node originated.

  • parent_tangent – Unit tangent of the parent meristem at origin.

  • radial_dir – Unit radial outward vector at the node’s divergence angle.

  • binormal_dir – Unit binormal vector perpendicular to parent_tangent and radial_dir.

  • age – Plastochron age ($t - t_{text{birth}} ge 0$) of the node.

  • generation – Branching depth ($1$ = primary lateral node, $2$ = secondary, etc.).

  • config – Propagation parameters.

Returns:

Tuple (path_points, tip_tangent, tip_normal, tip_binormal).

geometor.phyllotaxis.propagate_3d(steps: int, config: MeristemConfig | None = None) → list[MeristemNode]¶

Propagate a 3D phyllotaxic meristem system for steps plastochrons.

Node 0 is the primary apical meristem growing along $+Z$. At each step $t$, active meristems grow along their paths and emit new lateral child nodes at the divergence angle $Phi$ around their local tangent frame.

Parameters:

  • steps – Number of plastochron steps to simulate.

  • config – Optional MeristemConfig instance.

Returns:

List of MeristemNode instances (including the root stem and all lateral/recursive paths).

geometor.phyllotaxis.analyze_parastichy_curves(nodes: list[dict[str, float | int | str]], num_nearest: int = 3) → dict[str, object]¶

Count parastichy curves in each closest-neighbor rank and radial zone until they bend.

Demonstrates that the two primary closest-neighbor curve families wind in opposite directions (CW vs CCW) and always form a consecutive pair of Fibonacci numbers $(F_m, F_{m+1})$ within each radial zone between curve bends.

Parameters:

  • nodes – List of node dictionaries from vogel_points().

  • num_nearest – Number of closest inner nodes connected per node ($1 le k le 4$).

Returns:

  • outer_counts: Curve count $Delta$, winding direction ("CW" or "CCW"), and Fibonacci status for each rank at the outer rim.

  • opposing_pair: Tuple (cw_count, ccw_count) of the two primary opposing spiral families in the outer zone.

  • is_fibonacci_pair: True if opposing_pair consists of consecutive Fibonacci numbers with opposite chirality.

  • zones: Radial zones from inner to outer separated by bend radii.

Return type:

Dictionary containing

geometor.phyllotaxis.classify_meristem_phase(node_id: int, total_nodes: int, leaf_span: int = 34) → str¶

Classify a node’s ontogenetic organ type in the meristem’s production life cycle.

In a composite capitulum (such as a sunflower), the apical meristem transitions through distinct organ-production phases as the sequence progresses: 1. “leaf”: Early vegetative/involucral bracts (0 <= node_id < leaf_span). 2. “petal”: Ray florets / corolla petals (leaf_span <= node_id < leaf_span + round(leaf_span * φ)). 3. “floret”: Mature tubular disc florets in the capitulum interior. 4. “bud”: Newly initiated unopened primordia at the apical center (age < round(leaf_span / φ)).

geometor.phyllotaxis.vogel_points(num_nodes: int, scale: float = 5.0, angle_rad: float = GOLDEN_ANGLE_RAD, base_size: float = 1.5, growth_factor: float = 0.25, radial_acceleration: float = 0.0, leaf_span: int = 34) → list[dict[str, float | int | str]]¶

Compute 2D apical meristem coordinates with radial acceleration, node growth, and life-cycle phases.

New primordia emerge at the center ($k_{text{eff}} = (N - 1) - i$) while older primordia are displaced radially as $r = csqrt{k_{text{eff}}}left(frac{k_{text{eff}} + 1}{K_0}right)^{a}$, and node size grows as $s = s_0 + gsqrt{k_{text{eff}}}left(frac{k_{text{eff}} + 1}{K_0}right)^{1.15a}$.

Parameters:

  • num_nodes – Total number of primordia.

  • scale – Radial spread constant $c$.

  • angle_rad – Divergence angle in radians.

  • base_size – Initial radius of a newly emerged primordium ($s_0$).

  • growth_factor – Rate $g$ at which primordium size scales as it moves outward.

  • radial_acceleration – Acceleration exponent $a ge 0$ controlling how much faster older outer nodes move and expand compared to young inner primordia.

  • leaf_span – Characteristic Fibonacci cohort span for meristem life-cycle phases.

Returns:

List of dictionaries with keys id, age, phase, x, y, r, theta, size.
