.. py:function:: compute_node_path(origin: Vec3, parent_tangent: Vec3, radial_dir: Vec3, binormal_dir: Vec3, age: int, generation: int, config: MeristemConfig) -> tuple[list[Vec3], Vec3, Vec3, Vec3]

   Evaluate a node's 3D trajectory $\gamma(s)$ for $s \in [0, \text{age}]$ from `origin`.

   At $s = 0$, $\gamma(0) = \text{origin}$. As $s \to \text{age}$, the path advances
   outward along `radial_dir` and lifts/curves along `parent_tangent` with optional
   helical twist around `binormal_dir`.

   :param origin: 3D point on the parent meristem where this node originated.
   :param parent_tangent: Unit tangent of the parent meristem at `origin`.
   :param radial_dir: Unit radial outward vector at the node's divergence angle.
   :param binormal_dir: Unit binormal vector perpendicular to `parent_tangent` and `radial_dir`.
   :param age: Plastochron age ($t - t_{\text{birth}} \ge 0$) of the node.
   :param generation: Branching depth ($1$ = primary lateral node, $2$ = secondary, etc.).
   :param config: Propagation parameters.

   :returns: Tuple `(path_points, tip_tangent, tip_normal, tip_binormal)`.


.. py:function:: propagate_3d(steps: int, config: MeristemConfig | None = None) -> list[MeristemNode]

   Propagate a 3D phyllotaxic meristem system for `steps` plastochrons.

   Node `0` is the primary apical meristem growing along $+Z$. At each step $t$,
   active meristems grow along their paths and emit new lateral child nodes at
   the divergence angle $\Phi$ around their local tangent frame.

   :param steps: Number of plastochron steps to simulate.
   :param config: Optional `MeristemConfig` instance.

   :returns: List of `MeristemNode` instances (including the root stem and all lateral/recursive paths).
